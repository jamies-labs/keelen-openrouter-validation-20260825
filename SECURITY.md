# Security policy

This file is a starting point, not a policy. keelen scaffolded it so this
repository has a security contact from day one. Read it, edit it, and make it
yours before you invite reports from outside your team.

## Reporting a vulnerability

Send a private report to **security@example.com**.

REPLACE that address with your own. It is a placeholder. Nobody reads it, and
keelen does not receive reports for this repository.

In your report, include:

- the version or commit you tested,
- the steps to reproduce the problem,
- the impact you observed.

Do not open a public issue for a vulnerability. Do not test against systems you
do not own.

## Triage

The owner of this repository triages every report, writes the fix, and decides
on disclosure. There is no response time commitment here and there is no bug
bounty. Add both if you want them.
